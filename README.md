# Облачная читалка (CutePdfReader)

PDF-читалка для учебников под Windows 10/11: список текущих учебников и архив слева,
книга справа, каждая страница запоминается сама — даже если компьютер внезапно выключился.
Прогресс может синхронизироваться между компьютерами через OneDrive, обновления
приходят из GitHub Releases.

## Сборка

Двойной клик по `build.cmd` (или `powershell -File build.ps1`). Результат — один файл
`dist\CutePdfReader.exe` (~3,8 МБ). Если читалка запущена из `dist`, собрать можно
в другое место: `.\build.ps1 -Out obj\CutePdfReader.exe`.

Ничего ставить не нужно: используется компилятор C#, встроенный в Windows
(.NET Framework 4.8). Ограничение: он понимает только C# 5 — без `$"..."`, `?.`, `nameof`,
`=>`-членов и автосвойств с инициализаторами.

## PDF-движки

- **PDFium** (движок из Chrome, сборки [bblanchon/pdfium-binaries](https://github.com/bblanchon/pdfium-binaries))
  — основной. При первой сборке `tools\get-pdfium.ps1` скачивает закреплённую версию
  (проверяя SHA-256) в `third_party\pdfium`; сборка кладёт DLL внутрь exe в сжатом виде,
  а программа распаковывает её в `%LOCALAPPDATA%\CutePdfReader\engine\<версия>\` при первом запуске.
  Открывает и AES-256-зашифрованные учебники.
- **Windows.Data.Pdf** (встроен в Windows) — запасной: если PDFium не загрузился
  или не справился с конкретным файлом.

Лицензии PDFium и его зависимостей — в `third_party\pdfium\LICENSE.txt` и `licenses\`.

## Данные

`%APPDATA%\CutePdfReader\`:
- `library.json` — список учебников и позиции. Пишется через временный файл + замену,
  предыдущая версия лежит в `library.json.bak`.
- `pictures\` — картинки облачка, добавленные кнопкой.
- `log.txt` — ошибки.

Exe данных не содержит, поэтому его можно заменять/обновлять как угодно.

Для экспериментов: `set CUTEPDF_DATA=C:\temp\test` — отдельная библиотека (и отдельный
экземпляр программы), `set CUTEPDF_TRACE=1` — тайминги запуска в лог.

## Синхронизация

Меню «⋯» → «Синхронизация через OneDrive». В OneDrive появляется папка `CutePdfReader`:
- `devices\<id>.json` — каждый компьютер пишет только свой файл, поэтому конфликтов нет;
- `pictures\` — общие картинки облачка.

Книги узнаются по «отпечатку» содержимого PDF (SHA-256 размера и трёх мегабайт файла),
поэтому путь к файлу на разных компьютерах может быть любым. Учебник, которого на этом
компьютере ещё нет, показывается с прогрессом и подписью «перетащи сюда PDF».
Для каждой книги отдельно побеждает самая свежая позиция и самое свежее
название/архив. Вкладки книги (названия и их страницы) переезжают целиком — побеждает
самый свежий набор; какая вкладка открыта, каждый компьютер помнит сам.
Вместо OneDrive можно выбрать любую синхронизируемую папку.

## Перенос учебников флешкой

Сканы слишком большие для облака, поэтому PDF переносятся руками:
- «⋯» → «Собрать все учебники в папку (для флешки)…» — копирует все PDF в папку
  «Учебники из читалки» и кладёт рядом `cutepdf-progress.json` (страницы, архив, названия;
  формат как у файла устройства в синхронизации).
- На другом компьютере перетащить эту папку в окно (или «⋯» → «Забрать учебники из папки…»).
  Файлы с флешки копируются в `Документы\Учебники`, прогресс подхватывается даже без
  синхронизации, книги узнаются по отпечатку.

## Обновления

Репозиторий для обновлений задан в `src\Updater.cs` (`Sargonius/CutePdfReader`).

1. Перед выпуском поднять `AssemblyVersion` в `src\AssemblyInfo.cs`.
2. `.\release.ps1 "что нового"` — соберёт exe и создаст релиз (через `gh`, если он
   установлен, иначе откроет страницу нового релиза в браузере — останется прикрепить exe).

Читалка проверяет релизы через 20 секунд после запуска и раз в 6 часов. Если есть новее,
появляется кнопка «Обновить»: новый exe скачивается рядом со старым, старый
переименовывается в `*.old.exe`, программа перезапускается на той же странице.

## Вкладки

Кнопка с плюсиком в тулбаре открывает в том же учебнике ещё одну вкладку — например,
для ответов в конце книги. Вкладки стоят рядом с номером страницы, каждая помнит свою
страницу, переключение мгновенное (страницы соседних вкладок держатся отрисованными).
Двойной клик — переименовать, правый клик — удалить. Первая вкладка — это сама книга:
её страница идёт в прогресс-бар; если удалить первую, её место займёт следующая.
Масштаб у всех вкладок книги общий.

## Управление

| | |
|---|---|
| Колёсико, PgUp/PgDn, пробел, ↑↓ | листать |
| ← → | предыдущая / следующая страница |
| Ctrl + колёсико, Ctrl +/− | масштаб |
| Ctrl+0 | по ширине |
| Ctrl+G | перейти к странице |
| F2 / клик по названию | переименовать учебник |
| Ctrl+O | добавить PDF (или перетащить файлы/папку в окно) |
| Ctrl+B | спрятать список |
| Ctrl+T | новая вкладка в учебнике |
| Ctrl+Tab / Ctrl+Shift+Tab | следующая / предыдущая вкладка |
| F11 / Esc | полный экран |

## Устройство кода

- `src/ReaderView.cs` — непрерывная лента страниц; рисуются только видимые ± 2.
- `src/PdfDoc.cs` — общий интерфейс документа и движок Windows.Data.Pdf.
- `src/Pdfium.cs` — загрузка и P/Invoke-обёртка PDFium.
- `src/MainWindow.cs` — список учебников, тулбар, меню, связывает всё вместе.
- `src/Library.cs`, `src/Infrastructure.cs` — модель, отпечатки PDF, атомарная запись.
- `src/Sync.cs` — файлы устройств, слияние, слежение за папкой.
- `src/Updater.cs`, `release.ps1` — обновления через GitHub Releases.
- `src/Mascot.cs`, `src/CloudArt.cs` — облачко, фразы, иконка.
- `ui/*.xaml` — разметка и стили (грузятся в рантайме через XamlReader).
